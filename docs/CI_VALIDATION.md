# Fractional Quantity CI Validation

This branch exists only to execute pull-request validation for the current
fractional-quantity implementation in `feature/multi-user-cloud`.

- No application source is changed here.
- The pull request targets `feature/multi-user-cloud`, never `main`.
- The pull request is a draft and must not be merged.
- Validation includes Flutter analyze/tests, Android debug APKs, and Windows
  release packaging.
