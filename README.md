# عدة التاجر الذكي

نظام عربي لإدارة المتاجر على Windows وAndroid. المشروع حاليًا نموذج تطويري، وليس إصدارًا تجاريًا. راجع تقرير التدقيق وخارطة الطريق قبل استخدام بيانات حقيقية.

## حالة رأس الفرع
الفرع feature/multi-user-cloud يحتوي نواة Flutter وSQLite محلية لإدارة المنتجات والمخزون والمبيعات والمصروفات وتصدير CSV والنسخ الاحتياطي. توجد أساسات Supabase تجريبية، لكنها غير موصولة بواجهة التطبيق. لا توجد مزامنة منتج جاهزة، ولا إدارة فروع أو مشتريات مكتملة، ولا اختبار ميداني موثق.

## الوظائف المثبتة في المصدر
- واجهة عربية RTL.
- إضافة وبحث وتعديل وإيقاف المنتجات.
- حركات مخزون محلية تمنع الرصيد السالب افتراضيًا.
- فاتورة محلية متعددة الأصناف، تحفظ الفاتورة والبنود وتغييرات المخزون داخل معاملة.
- مصروفات وملخص ربح أولي؛ تكلفة الصنف ليست متوسطًا مرجحًا بعد.
- تصدير CSV وواجهة نسخ واستعادة محلية؛ يجب استكمال اختبار الاستعادة على جهاز.

وجود الشيفرة أو مرور CI لا يعني أن الوظيفة اختبرت ميدانيًا أو صارت جاهزة تجاريًا.

## ما لم يكتمل
المشتريات والموردون والعملاء، المخازن والفروع، المرتجعات، ورديات الصندوق، سياسة المتوسط المرجح، الطباعة، دخول المستخدمين من التطبيق، صلاحيات الخادم المتكاملة، مزامنة عدة أجهزة، الأمان والنسخ الاحتياطي الميداني.

لا يحسب النظام الضرائب. يمكن تسجيل مبلغ ضريبي مدفوع يدويًا كمصروف عادي.

## البناء والتحقق
راجع docs/BUILD_AND_VALIDATE.md. نتائج CI الحالية تخص GitHub Actions فقط. APK الحالية debug للاختبار وليست إصدار متجر، وحزمة Windows لم تختبر بعد على جهاز نظيف.
