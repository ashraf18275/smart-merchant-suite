# عدة التاجر الذكي | Smart Merchant Suite

برنامج عربي لإدارة المحلات التجارية، يستهدف الكمبيوتر وأندرويد، مع وظائف محلية دون إنترنت ومزامنة اختيارية عند توفر الاتصال.

> **الحالة الحالية:** أضيف هيكل Flutter أولي وشاشة عربية RTL تعرض الأقسام المخططة. لم يتم بعد تأكيد نجاح البناء أو تشغيل اختبارات Flutter؛ وظائف البيع والمخزون والحسابات والمزامنة ما زالت غير منفذة.

## الوثائق
- [مواصفات المنتج والبنية التقنية](docs/PRODUCT_SPEC.md)
- [معايير القبول والاختبارات المخططة](docs/ACCEPTANCE_TESTS.md)
- [خارطة طريق التنفيذ](docs/ROADMAP.md)

## الملفات الأساسية
- `lib/main.dart`: غلاف التطبيق وشاشة الأقسام التمهيدية.
- `test/widget_test.dart`: اختبار واجهة أولي مخطط للتشغيل.
- `.github/workflows/flutter-ci.yml`: سير عمل للتحليل والاختبارات عند تشغيله.

## التقنية المقترحة
Flutter للواجهة المشتركة وSQLite للتخزين المحلي (لم تُضف قاعدة البيانات بعد). اختيار الخادم وخدمة المزامنة مؤجل حتى تتضح متطلبات تعدد الأجهزة والتكلفة والخصوصية.

## الجودة والتطوير
يُستخدم فرع منفصل لكل مجموعة تغييرات. لا يُدمج أي تغيير إلى `main` قبل مراجعة الملفات وتشغيل الفحوص المناسبة وتسجيل نتائجها. لا تُعلن أي ميزة أو نتيجة اختبار قبل التحقق الفعلي.
