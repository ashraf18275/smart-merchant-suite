# عدة التاجر الذكي | Smart Merchant Suite

برنامج عربي لإدارة المحلات التجارية، يستهدف الكمبيوتر وأندرويد، مع وظائف محلية دون إنترنت ومزامنة اختيارية عند توفر الاتصال.

> **حالة المشروع:** مرحلة التأسيس والتخطيط. لا يوجد في هذا الفرع ما يثبت أن التطبيق نفسه بُني أو أن اختبارات القبول نُفذت. وثائق المواصفات ومعايير القبول خطط أولية.

## الوثائق
- [مواصفات المنتج والبنية التقنية](docs/PRODUCT_SPEC.md)
- [معايير القبول والاختبارات المخططة](docs/ACCEPTANCE_TESTS.md)
- [خارطة طريق التنفيذ](docs/ROADMAP.md)

## المبادئ
- البيانات الأساسية تعمل محليًا.
- حفظ مالي ومخزني متسق داخل معاملات قاعدة البيانات.
- نسخ احتياطي واستعادة يجب اختبارهما عمليًا.
- مزامنة آمنة تمنع تكرار العمليات وتعالج التعارضات.
- واجهة عربية RTL.
- النسخة المجانية مفيدة، والترخيص المدفوع لا يحبس بيانات المستخدم.

## التقنية المقترحة
Flutter + SQLite للنواة المحلية. اختيار الخادم وخدمة المزامنة مؤجل إلى أن تتضح متطلبات تعدد الأجهزة والتكلفة والخصوصية.

## التطوير
يُستخدم فرع منفصل لكل مجموعة تغييرات. لا يُدمج أي تغيير إلى `main` قبل مراجعة الملفات وتشغيل الفحوص المناسبة وتسجيل نتائجها.
