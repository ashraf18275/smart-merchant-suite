# عدة التاجر الذكي | Smart Merchant Suite

تطبيق عربي لإدارة المحلات التجارية، مبني بـ Flutter مع واجهة RTL وتخزين محلي عبر SQLite. يستهدف أندرويد والكمبيوتر، وتُطوّر الوظائف على مراحل مع اختبارات آلية.

> **الحالة الحالية:** نسخة تطويرية محلية وليست إصدارًا جاهزًا للاستخدام التجاري. يتضمن الفرع الحالي إدارة المنتجات والمخزون، وتسجيل فاتورة بيع أولية لمنتج واحد مع تحديث المخزون ذريًا، وتسجيل المصروفات وعرض ملخص إجمالي للأرباح. لا يزال الإصدار تجريبيًا، وتبقى تقارير الفترات والمرتجعات والنسخ الاحتياطي والمزامنة قيد التطوير.

## الوظائف المتاحة في فرع التطوير
- واجهة عربية من اليمين إلى اليسار.
- تخزين المنتجات محليًا في SQLite.
- إضافة منتج بالاسم والكود الاختياري والتكلفة وسعر البيع والكمية الافتتاحية.
- البحث بالاسم أو الكود.
- تعديل بيانات المنتج مع الحفاظ على رصيد المخزون.
- تسجيل زيادة أو صرف للمخزون مع سبب للحركة وسجل تدقيق.
- رفض المخزون السالب، ومنع حركات المخزون للمنتج الموقوف.
- إيقاف المنتج أو إعادة تفعيله دون حذف بياناته أو حركاته السابقة.
- اختبارات وحدة وواجهة للوظائف الأساسية، مع فحص Flutter آلي عبر GitHub Actions.

## ما لم يُنفذ بعد
- تصنيفات المنتجات ووحدات القياس والجرد المتقدم.
- دعم الفواتير متعددة الأصناف، والخصومات والمرتجعات وإدارة المدفوعات المتقدمة.
- الفواتير متعددة الأصناف والخصومات والمرتجعات والمدفوعات المتقدمة.\n- تقارير حسب فترة زمنية وتصفية الأرباح بالتاريخ.
- تصدير CSV والنسخ الاحتياطي والاستعادة.
- اختبارات فعلية على أجهزة الكمبيوتر وأندرويد والطباعة.
- المزامنة بين الأجهزة والترخيص.

## الملفات الأساسية
- `lib/main.dart`: نقطة الدخول ولوحة الأقسام.
- `lib/data/local_database.dart`: فتح قاعدة البيانات المحلية حسب المنصة.
- `lib/data/product_repository.dart`: مخزن بيانات المنتجات وحركات المخزون.\n- `lib/data/sales_repository.dart`: إنشاء فواتير البيع الذرية.\n- `lib/data/expense_repository.dart`: المصروفات وملخص الأرباح.
- `lib/features/products_page.dart`: واجهة المنتجات والمخزون.
- `test/`: اختبارات الوحدة والواجهة.
- `.github/workflows/flutter-ci.yml`: فحوص التحليل والاختبارات الآلية.

## التقنية
- Flutter / Dart للواجهة.
- SQLite للتخزين المحلي.
- `sqflite` للأجهزة المدعومة و`sqflite_common_ffi` لاختبارات/بيئات سطح المكتب.
- تخزين الأموال في وحدات نقدية صحيحة (قروش) لتجنب أخطاء الأعداد العشرية.

## الجودة وسلامة البيانات
لا تُعلن أي ميزة مكتملة إلا بعد إضافة اختبارات مناسبة وفحص نتائج GitHub Actions. تُنفذ التغييرات على فرع التطوير، ولا يتم دمجها إلى `main` دون موافقة صريحة ومراجعة.
